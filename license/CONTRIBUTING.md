# Contributing to SlopOn

Thank you for your interest in improving SlopOn.

## How to propose changes

- For bugs and feature requests, open an issue in the official SlopOn repository.
- For code changes, open a pull request against the official repository. Keeping each pull request focused on a single change makes review faster.

## Contributor Assignment Agreement

All contributions are governed by the [SlopOn Contributor Assignment Agreement](CONTRIBUTOR-ASSIGNMENT-AGREEMENT.md), under which you assign copyright in your contribution to the licensor (with a license-back to you for your own contribution).

**By Submitting a Contribution — including opening a pull request — you agree to the SlopOn Contributor Assignment Agreement.**

Once the source repository is public, an automated signing mechanism (a CLA-assistant bot) will gate merges; maintainers cannot merge a pull request until the agreement has been accepted.

## Why assignment is required

Sharing modifications to SlopOn is only permitted by contributing them back to the official project (see Section 7 of the [SlopOn Community License](LICENSE.md)). Copyright assignment lets the licensor distribute SlopOn and your contribution under both the Community License and commercial licenses.
